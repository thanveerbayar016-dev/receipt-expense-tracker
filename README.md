# Receipt & Expense Tracker

A simple responsive web application for recording and monitoring daily expenses.

## Features
- Add expense description, amount, category and date
- View total spending and transaction count
- Delete individual expenses
- Clear all expenses
- Data is stored in the browser using localStorage
- Responsive design

## Run locally
Open `index.html` in a web browser.

## Deployment
This project can be deployed directly to Vercel, Netlify, or GitHub Pages.
